# Worklog

Daily troubleshooting and change-handling stream, organized by date, forming traceable history.

## Usage

- One file per day, named `YYYY-MM-DD.md` (e.g. `2026-09-17.md`).
- All investigations/changes on the same day are appended to that day's file in chronological order.
- Each entry is separated by `## <Title>` and contains: time, problem, investigation steps, root cause, resolution, follow-up.

## Notes

- Major incidents should also produce a `../incidents/` retrospective.
