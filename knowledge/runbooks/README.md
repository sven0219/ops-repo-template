# Runbooks

Executable operational procedure manuals. Each document must state its verification status (verified / unverified).

## Usage

- Copy `../_template.md` or follow the existing runbook format.
- Commands must be directly executable — no ambiguity.
- Mark the `status` in the frontmatter and note actual verification.
