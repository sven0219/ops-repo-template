# Incidents

Major incident retrospectives. Daily operational flow is recorded in `../worklog/`; major incidents get a standalone retrospective here.

## Usage

- Copy `_template.md` for new retrospectives.
- File naming: `YYYY-MM-DD-<short-slug>.md`.
- Each retrospective links back to the corresponding worklog record.
- A retrospective should include: timeline, root cause, impact, resolution, improvement actions.
